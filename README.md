# ChamaÊ 🌿

O **ChamaÊ** é uma plataforma desenvolvida em React que conecta clientes a profissionais autônomos, facilitando a divulgação e busca por serviços e aproximando pessoas que precisam das soluções de quem pode oferecê-las.

## Funcionalidades

- Página inicial com apresentação da plataforma.
- Catálogo de serviços disponíveis.
- Área de login.
- Cadastro de clientes.
- Cadastro de profissionais.
- Navegação entre páginas sem recarregamento, utilizando React Router.
- Componentes reutilizáveis para a interface.

## Tecnologias utilizadas

- React
- JavaScript
- React Router DOM
- CSS Modules
- HTML5 e CSS3

## Estrutura do projeto

- `src/components`: componentes reutilizáveis, como Navbar, Rodapé e cards de serviços.
- `src/pages`: páginas da aplicação.
- `src/images`: imagens utilizadas no projeto.

## Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/laisecamarao/chamae.git
   ```

2. Entre na pasta:

   ```bash
   cd chamae
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie a aplicação:

   ```bash
   npm start
   ```

5. Acesse `http://localhost:3000` no navegador.

## Observação

Este projeto foi desenvolvido para fins acadêmicos. As funcionalidades de login e cadastro são demonstrativas e não possuem integração com banco de dados ou sistema de autenticação.
